# DinoDiT 与 Pixel JiT 两阶段训练（pred_drop 修复版）

在 `jit_cond_dino_two_stage_1122` 基础上修复一处 pred 模式的 train-test gap。

## 修改点

### P1：pred 模式补全 label dropout（`denoiser.py`）

原版 `prepare_grounding_pixel` 在 pred 模式下直接用原始 `labels` 调用冻结 DinoDiT，
训练时 Pixel JiT 从未见过 DinoDiT 在 null label 下的输出 token。
推理时 DinoDiT CFG 实际输出的是 `uncond + w*(cond−uncond)` 的混合 token，
分布与训练时不一致。

修改后，用独立 dropout 的 `labels_for_dino` 调用 DinoDiT，使 Pixel 训练覆盖两种 token 分布：

```python
# 旧
z_cond = self.dino_net(z_cond, t_d_p, labels)

# 新
labels_for_dino, _ = self.drop_labels_with_mask(labels)
z_cond = self.dino_net(z_cond, t_d_p, labels_for_dino)
```

Pixel 侧的 `labels_dropped` 和这里的 `labels_for_dino` 是两次独立 dropout，互不干扰。

## 入口与文件分工

| 路径 | 作用 |
| --- | --- |
| `stage1/main_dino.py` | Stage 1 独立训练入口，自己解析参数、创建 DinoDiT、运行 epoch 循环并保存 checkpoint。 |
| `stage1/denoiser_dino.py` | 冻结图像 encoder、定义 DinoDiT 的 latent 加噪和训练 loss。两阶段共用这里的 latent 编码与采样。 |
| `stage1/dino_dit.py`、`stage1/lf_modules.py`、`stage1/model_util.py` | DinoDiT 网络及原 `latent_force/` 中仅供 DINO 分支使用的构件。 |
| `stage1/dinov2_encoder.py`、`stage1/dinov3_backbone.py` | 图像 encoder 与 latent 归一化，供两个阶段读入相同的 DINO 特征空间。 |
| `main_jit.py`、`denoiser.py`、`engine_jit.py` | Stage 2 的训练入口、Pixel 条件和流匹配目标、图像评估。 |
| `util/training.py`、`util/train_epoch.py`、`checkpoint_io.py` | 两阶段共用的数据、optimizer、单轮反向与 checkpoint 工具。 |
| `sh/train_dino.sh`、`sh/train_pixel.sh`、`sh/sample_pixel.sh` | 分别启动 Stage 1 训练、Stage 2 训练和 Stage 2 采样。 |

`stage1/main_dino.py` 以模块 `stage1.main_dino` 启动，直接构建 `DinoDenoiser`。训练仅更新 `dino_net`。Stage 2 的 `main_jit.py` 构建 Pixel JiT，并通过 `--dino_checkpoint` 加载 Stage 1 的 `dino_net`（默认 EMA1）和冻结图像 encoder。Stage 2 仅更新 Pixel JiT 和它的条件投影。两个阶段各自拥有训练循环、optimizer、EMA 和 checkpoint。

## 三个时间变量

| 代码变量 | 含义 |
| --- | --- |
| `t_p`（`t_pixel`） | Pixel 流匹配时间，用于 RGB 像素的加噪和去噪，训练默认 `sigmoid(N(-0.8, 0.8²))`。 |
| `t_d`（`t_dino`） | DinoDiT 流匹配时间，用于 Stage 1 的 latent 加噪和去噪，训练默认 `sigmoid(N(-1.2, 1.0²))`，也用于采样阶段的 latent 积分。 |
| `t_d_p`（`t_dino_pixel`） | Stage 2 对 clean DINO latent 加噪时使用的时间。默认 `U[0.75, 1)`，由 `--noise_beta_dino_pixel 0.25` 控制。`--t_schedule_dino_pixel logit_normal` 可改用 DINO 的 logit-normal 分布。 |

两个分支的时间都采用 `0` 为纯噪声、`1` 为干净端的约定。Pixel JiT 保留原来的 `t_dino` 接口，这个参数接收的是**当前 grounding 的时间标记**，由下列模式决定。

## Stage 2 条件消融

设 `g` 是 clean 图像经冻结 DINO encoder 提取并按 latent 统计归一化的特征，形状为 `[B,768,16,16]`。两个模式都用 `t_d_p` 构造带噪 latent `z = t_d_p * g + (1 - t_d_p) * epsilon_dino`。

- **`--condition_mode_pixel noised`** 把 `z` 展平为 `[B,256,768]` 后直接注入。Pixel 条件为 `E_p(t_p) + E_y(y) + E_d(t_d_p) + W_g(z)`。训练时的轻噪声用来模拟采样 grounding 的误差。
- **`--condition_mode_pixel pred`** 用冻结 DinoDiT 做一次 `g_hat = dino_net(z, t_d_p, y)`，再展平预测结果并注入。Pixel 条件为 `E_p(t_p) + E_y(y) + E_d(1) + W_g(g_hat)`。`1` 标记预测的 clean 端点，实际预测仍可以带误差。

两种模式都只计算 Pixel velocity loss。类别 dropout 同时屏蔽 grounding 和它的时间 embedding。采样都先用 DinoDiT 从纯噪声多步生成 latent，再让 Pixel JiT 在 `t_dino=1` 下生成 RGB。`noised` 模式的 Stage 2 仍加载同一份 Stage 1 checkpoint，供采样使用。可分别设置 `--cfg_dino` 和 `--cfg_pixel`，以及 `--noise_scale_dino` 和 `--noise_scale_pixel`。
