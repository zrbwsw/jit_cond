# Independent DinoDiT + predicted-condition Pixel JiT

Forked from the working tree of `../JiT_cond_join_dino`. Original experiments,
checkpoints and logs are not modified or copied into this directory.

See [中文改动说明.md](中文改动说明.md) for the conditioning equations and caveats.

## Two independent training stages

| Entry | Trainable | Frozen | Objective |
| --- | --- | --- | --- |
| `main_dino.py` | `dino_net` | DINO image encoder | DINO latent velocity loss |
| `main_jit.py` | Pixel `net` | pretrained `dino_net`, image encoder | Pixel velocity loss only |

Pixel training pairs each image with **one clean-token prediction** from
`DinoDiT(s * DINO(image) + (1-s) * noise, s, label)`.
There is no DinoDiT loss, backward pass, optimizer state or EMA in this stage.
Both frozen networks remain in eval mode, including after `model.train()`.
The prediction runs under `torch.no_grad()`; no conditioning `detach()` is needed.

The default input corruption time is `s ~ U[0.75, 1)` (noise beta 0.25).
`--condition_time_schedule logit_normal` instead uses `D_mean/D_std` over (0,1).
Pixel always receives `t_dino=1`, because its condition is a predicted clean
latent, not the noisy DinoDiT input. Pixel label dropout also masks the tokens
and their time embedding. DinoDiT's single training-condition prediction uses
the original label and CFG=1, regardless of the generation `--dino_cfg` setting.

At inference the existing two-stage sampler is preserved: sample DINO latents
from pure noise (25 steps by default), then sample pixels (50 steps). These are
not single-step unconditional samples. Training on predictions narrows, but
does not eliminate, the reconstruction-versus-generation distribution gap.

## Run on this server

Use the existing `irepa` environment (PyTorch, torchvision, timm, transformers,
tensorboard, scipy, OpenCV, einops, torch-fidelity). No new environment is created.
The supplied statistics and encoders currently support ImageNet 256, 768x16x16
latent tensors. No network download is needed if encoder weights are local.

```bash
cd /data0/zhangruobei/Work/jit_cond_ablation/jit_cond_predict_independent_dino

# Optional: train DinoDiT separately. Omit this if reusing a joint checkpoint.
bash sh/run.sh dino --dry-run
bash sh/run.sh dino

# Pixel from scratch, frozen DINO EMA1 extracted from a TRUSTED joint checkpoint.
bash sh/run.sh pixel --dry-run --dino_checkpoint /path/to/join/checkpoint-80.pth
bash sh/run.sh pixel --dino_checkpoint /path/to/join/checkpoint-80.pth

# Alternatively use a newly trained standalone DINO checkpoint.
bash sh/run.sh pixel --dino_checkpoint /path/to/dino/checkpoint-80.pth

# Resume ONLY the corresponding new independent stage, including optimizer/EMA.
bash sh/run.sh pixel --resume /path/to/pixel/checkpoint-last.pth
bash sh/run.sh dino --resume /path/to/dino/checkpoint-last.pth

# Class-only generation with Pixel EMA1 + the exact frozen DinoDiT saved with it.
bash sh/run.sh sample --checkpoint /path/to/pixel/checkpoint-80.pth
```

The `/path/to/...` values must be replaced with real checkpoint files. The source
folder currently has training logs but no local join-dino `.pth` checkpoints.
No checkpoint is selected implicitly, downloaded or generated by this change.

`CUDA_VISIBLE_DEVICES=0,1,2,3` limits a launcher to four GPUs; default is all eight.
With the default 128 images/GPU, global batch is 1024 on eight GPUs and learning
rate is 2e-4 (`blr * global_batch / 256`). Override `--batch_size` / `--lr` when
changing the GPU count if a controlled batch/LR comparison is needed.
`PYTHON_BIN`, `OUTPUT_DIR`, `DINO_ENCODER` can be set in the environment. CLI
arguments appended to `sh/run.sh` override its defaults. Launchers do not silently
resume; pass `--resume` explicitly. `--online_eval` is optional for Pixel only.
Direct `python main_dino.py ...` / `python main_jit.py ...` also support one GPU.

Resource overrides: `IMAGENET_ROOT`, `PRETRAIN_MODELS_ROOT`, `DINOV3_REPO`,
`FID_STATS_ROOT`, or `--data_path`, `--dinov3_weights`, `--dinov3_repo`,
`--dino_stat_path`. This server defaults to `/data0/datasets/imagenet`,
`/data0/pretrain_models` and the existing local DINOv3 source/FID statistics.
DINOv2 needs `dinov2-with-registers-base/` under the pretrain root or a populated
Hugging Face cache. Match `--dino_encoder` and statistics to the source checkpoint.

## Checkpoint compatibility

- `--dino_checkpoint`: loads **only `dino_net.*` plus the frozen image encoder**.
  Accepts old join-dino or new standalone DINO checkpoints. No old optimizer
  or training epoch is imported. `--dino_weights model|ema1|ema2` defaults to EMA1.
  To reuse the frozen teacher embedded in a new Pixel checkpoint, explicitly
  select `--dino_weights model`: Pixel checkpoints have no DinoDiT EMA entries.
- `--init_pixel`: optional Pixel-only warm start from a compatible joint/new
  Pixel checkpoint. `--init_pixel_weights` defaults to `model`. This is fine-tuning,
  not the from-scratch experiment. It never replaces the chosen frozen DinoDiT.
- `--resume`: only accepts checkpoints from the **same independent stage**.
  A missing file, mismatched stage, encoder, model shape, statistics or relevant
  conditioning settings is an error, not a silent restart or partial load.
- New checkpoints contain both frozen networks in `model` for Pixel resume, but
  `model_ema1/2` and optimizer contain only that stage's trainable parameters.
  EMA is matched by parameter name, never by old joint parameter ordering.
  Saves use a temporary file plus atomic replacement; the previous checkpoint
  is not truncated while a resumed optimizer may still reference mapped tensors.
- A Pixel checkpoint therefore retains the exact teacher weights used in training;
  the original `--dino_checkpoint` file is not needed for resume/sampling. Local
  encoder construction resources and the matching statistics are still needed.
- Old checkpoints do not fingerprint statistics. Their encoder/architecture
  metadata is checked, but verify that their original statistics match these files.
- Checkpoints contain pickled `argparse.Namespace`; load trusted files only.

Standalone DINO keeps the original logit-normal noise distribution
`sigmoid(N(-1.2,1))`, label dropout and flow objective. Its loss scale defaults to
1; `--dino_loss_scale 0.333` retains the former joint objective multiplier.
Independent objectives do not imply bit-identical training trajectories after
changing RNG consumption, optimizer grouping, EMA choice or training schedule.

## Verification

```bash
python -m pytest tests -q
```

Tests exercise frozen teacher mode/gradients, one-forward clean conditioning,
label dropout, time schedules, named legacy EMA extraction, independent resume,
atomic saves, EMA restoration and generation without ground-truth images. They
include small real Transformer blocks and an end-to-end synthetic CPU training
and resume run; they do not require or test a full ImageNet training job.
