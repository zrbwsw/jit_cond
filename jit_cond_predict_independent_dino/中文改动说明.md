# 独立 DinoDiT 与预测条件 Pixel JiT

本目录来自 `JiT_cond_join_dino` 当前工作区，不修改原目录，不复制 checkpoint 和实验输出。

## 解耦后的训练

1. `main_dino.py` 仅创建、训练 DinoDiT；冻结图像 DINO encoder，不创建 Pixel JiT。
2. `main_jit.py` 从指定 checkpoint 加载 DinoDiT 并冻结，仅训练 Pixel JiT。
3. 两个阶段分别保存 optimizer、EMA、epoch；Pixel loss 不回传 DinoDiT。

原联合模型的两路 trunk 没有共享参数，因此目标在参数梯度上可以分开优化。
但改变随机数消费顺序、loss 系数、训练时间表或使用固定 EMA teacher 后，不能声称每步参数与联合训练完全一致。

## Pixel 新条件

对当前训练图像 x，令 `h = DINO_encoder(x)`：

```text
s ~ Uniform[0.75, 1)                         # 默认保持原有 <=25% 加噪范围
h_s = s * h + (1-s) * epsilon
h_pred = frozen_DinoDiT(h_s, s, original_y) # 只有一次 forward，输出 clean latent
pixel_condition = tokens(h_pred)
pixel_t_dino = 1
loss = pixel_velocity_loss
```

预测链路使用 `requires_grad_(False)`、`eval()` 和 `torch.no_grad()`，不需要 detach。
这里使用 no_grad 而非 inference_mode，预测 token 仍能被后续可训练线性层保存用于自身反向计算。
训练时不执行 DINO 多步积分、不把预测转成 velocity，也不对预测结果再次加噪。
Pixel 类别 dropout 时同时遮掉 token 和 t_dino 条件；冻结 DinoDiT 本身使用原始类别。

`s` 是 DinoDiT 输入的噪声时间，不是 Pixel 收到的 clean-token 时间标签。
Pixel 在训练与采样中均使用 `t_dino=1`，避免训练以噪声标签解释预测 clean token。
如果要覆盖完整噪声区间，显式指定 `--condition_time_schedule logit_normal`，使用 D_mean/D_std；
不影响独立 DinoDiT 预训练，它始终沿用原本完整的 logit-normal 时间分布。

## 复用权重与采样

- 旧联合 checkpoint 通过 `--dino_checkpoint` 提取 `dino_net.*` 和其冻结 encoder，默认取 EMA1。
- 可选 `--dino_weights model` / `ema2`；缺少指定 EMA 参数会报错，不静默退回原始权重。
- 不传 `--init_pixel` 时 Pixel 随机初始化；提供该参数属于另一组 warm-start 实验。
- 不用旧联合 checkpoint 做 `--resume`，避免 optimizer/EMA 参数集合错配。
- Pixel EMA 只更新 Pixel，生成时不替换固定 DinoDiT。
- 生成仍从纯噪声多步生成 DINO latent，再生成图像，不需要验证集图像。

训练单次预测默认 CFG=1；采样 `--dino_cfg` 可以调节，但 CFG>1 会引入额外条件分布差异。
即便都使用模型输出，“GT 加噪后重建”与“纯噪声完整生成”也不是同一个分布。
本实验检验 Pixel 对真实预测误差的适应性，不预先宣称完全消除了预测误差或必然改善 FID。

运行命令、路径覆盖和检查方法见 [README.md](README.md)。没有自动启动训练任务。
