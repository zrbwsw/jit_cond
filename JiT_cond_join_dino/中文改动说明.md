# JiT_cond_join_dino 改动说明

本目录在 `JiT_cond`（patch-level AdaLN）基础上，把 grounding 的来源换成一个
独立训练的 **dino DiT**，并把 Latent Forcing 两路相加、共享 trunk 的融合方式，
改成 JiT 侧的条件注入 `c = t + y + t_dino + W_g·grounding`。参数量约翻倍。

## 新增 `latent_force/`

| 文件 | 来源 / 作用 |
| --- | --- |
| `lf_modules.py` | 逐字摘自 LatentForcing `model_cot.py`（上游 HEAD）第 16–225 行：`modulate`/`BottleneckPatchEmbed`/`TimestepEmbedder`/`LabelEmbedder`/`Attention`/`SwiGLUFFN`/`FinalLayer`/`JiTBlock`。唯一改动是 RoPE/RMSNorm 改为包内导入 |
| `model_util.py` | LatentForcing `util/model_util.py`，RoPE buffer 去掉硬编码 `.cuda()`，改为非持久 buffer（CPU 可构造，不进 state_dict） |
| `dinov2_encoder.py` | 复刻 LF `RAE.encode` 的 DINOv2-reg-B/14 latent 编码（去掉 LatentForcing 独有的 ×0.485），去掉未用的 noise_tau 分支和 `@torch.compile`，统计文件默认指向本目录随附文件 |
| `dino_dit.py` | 独立 dino DiT（`DinoDiT-B` = JiT-B 同尺寸：12 层 / 768 / 12 头），输入经 LF 式 bottleneck，x-prediction 输出 unpatchify 回 `[B,768,16,16]` |
| `dinov2_wreg_base_imagenet1k_stat.pt` | RAE 发布的 ImageNet-1k latent 方差（`mean=None`，`var=[768,16,16]`），用于归一化 |

验证：本目录 encoder 与 `lfjit-l-200.pth` 内置 `dino.*` 权重在同一张图上编码，
逐元素 `max|diff|=0`。

## `model_jit.py`

只加了一处：`JiT.__init__` 新增 `use_t_dino`，启用时构造 `t_dino_embedder`
（与 `t_embedder` 不共享权重），`forward` 多接收 `t_dino` 并加进全局条件
`c = t_emb + y_emb + t_dino_emb`。被 `grounding_mask` 屏蔽的样本（CFG 无条件
分支）其 `t_dino_emb` 一并清零，规则与 semantic 项一致。其余 patch-level AdaLN
逻辑完全沿用 JiT_cond。

## `denoiser.py`（重写）

* 构造 `dino_net`（DinoDiT）与冻结的 `dino_encoder`（DINOv2）。
* `forward` 返回 `(loss, {loss_jit, loss_dino})`，每个样本两路都监督：
  * JiT path：`z = t·x + (1−t)·e`，grounding 取 `t_dino∈[1−β,1)` 的带噪 clean
    latent，`t_dino` 传进条件；
  * dino path：独立去噪 DINOv2 latent，`t_dino` 调度 follow LF。
* `sample_dino_latent`：dino DiT 从噪声采 `dino_steps` 步（可带 dino CFG），
  返回 `t_dino=1` 的 latent。
* `generate`：先采 grounding，再整条 JiT 轨迹复用（instance-level）。
* `update_ema`：JiT 和 dino DiT 的可训练参数都纳入；冻结 DINOv2 不进 EMA。

## `engine_jit.py`

* 训练循环接收 `(loss, loss_dict)`，TensorBoard 额外记录 `train_loss_jit`、
  `train_loss_dino`。
* `evaluate` 去掉 val 配对（instance/class-level），`generate(labels_gen)` 只传
  标签，grounding 由 dino DiT 内部生成。

## `main_jit.py`

移除 DINOv3 相关参数（`grounding_model/weights/repo/source`、`val_grounding_level`
等），改为 join-dino 参数：`--dino_model`、`--dinov2_path`、`--dino_stat_path`、
`--D_mean/--D_std`、`--dino_weight`、`--dino_noise_beta`、`--dino_steps`、
`--dino_sampling_method`、`--dino_cfg`、`--dino_interval_min/max`。EMA 恢复逻辑
不变（按运行时 `requires_grad` 名单），已验证 checkpoint 往返和 EMA 切换一致。

## 删除的继承文件

`grounding.py`（DINOv3 编码器）、`dinov3_backbone.py`、`val_grounding.py`、
旧 `tools/verify_*`、`prepare_ref.py`——join-dino 均不使用。

## 已验证（CPU）

* 可训练参数 263.6M ≈ JiT 132.7M + dino DiT 131.3M；冻结 DINOv2 87M 不计。
* 训练 forward 两路均有梯度，DINOv2 无梯度。
* dino latent 采样 `[B,768,16,16]`、`generate` 输出 `[B,3,256,256]` 数值有限。
* checkpoint 保存→恢复→EMA 切换→再 generate 全链路通过，EMA 名单 370 一致。

尚未在 GPU 上实训，训练前建议先跑若干步确认 loss 下降。
