# DinoDiT 与 Pixel JiT 两阶段训练

本版从 `jit_cond_predict_independent_dino` 拆出独立的 DinoDiT 训练入口，并为 Pixel JiT 提供三种训练条件。`model_jit.py` 沿用上一版的 patch-level AdaLN。

## 入口与文件分工

| 路径 | 作用 |
| --- | --- |
| `stage1/main_dino.py` | Stage 1 独立训练入口，自己解析参数、创建 DinoDiT、运行 epoch 循环并保存 checkpoint。 |
| `stage1/denoiser_dino.py` | 冻结图像 encoder、定义 DinoDiT 的 latent 加噪和训练 loss。两阶段共用这里的 latent 编码与采样。 |
| `stage1/dino_dit.py`、`stage1/lf_modules.py`、`stage1/model_util.py` | DinoDiT 网络及原 `latent_force/` 中仅供 DINO 分支使用的构件。 |
| `stage1/dinov2_encoder.py`、`stage1/dinov3_backbone.py` | 图像 encoder 与 latent 归一化，供两个阶段读入相同的 DINO 特征空间。 |
| `main_jit.py`、`denoiser.py`、`engine_jit.py` | Stage 2 的训练入口、Pixel 条件和流匹配目标、图像评估。 |
| `util/training.py`、`util/train_epoch.py`、`checkpoint_io.py` | 两阶段共用的数据、optimizer、单轮反向与 checkpoint 工具。 |
| `sh/train_dino.sh`、`sh/train_pixel.sh`、`sh/sample_pixel.sh` | 分别启动 Stage 1 训练、Stage 2 训练和 Stage 2 采样。 |

`stage1/main_dino.py` 以模块 `stage1.main_dino` 启动，直接构建 `DinoDenoiser`。训练仅更新 `dino_net`。Stage 2 的 `main_jit.py` 构建 Pixel JiT，并通过 `--dino_checkpoint` 加载 Stage 1 的 `dino_net`（默认 EMA1）和冻结图像 encoder。Stage 2 仅更新 Pixel JiT 和它的条件投影。两个阶段各自拥有训练循环、optimizer、EMA 和 checkpoint。

## 三个时间变量

| 代码变量 | 含义 |
| --- | --- |
| `t_p`（`t_pixel`） | Pixel 流匹配时间，用于 RGB 像素的加噪和去噪，训练默认 `sigmoid(N(-0.8, 0.8²))`。 |
| `t_d`（`t_dino`） | DinoDiT 流匹配时间，用于 Stage 1 的 latent 加噪和去噪，训练默认 `sigmoid(N(-1.2, 1.0²))`，也用于采样阶段的 latent 积分。 |
| `t_d_p`（`t_dino_pixel`） | Stage 2 对 clean DINO latent 加噪时使用的时间。默认 `U[0.75, 1)`，由 `--noise_beta_dino_pixel 0.25` 控制。`--t_schedule_dino_pixel logit_normal` 可改用 DINO 的 logit-normal 分布。 |

两个分支的时间都采用 `0` 为纯噪声、`1` 为干净端的约定。

## Stage 2 条件消融

设 `g` 是 clean 图像经冻结 DINO encoder 提取并按 latent 统计归一化的特征，形状为 `[B,768,16,16]`。clean 直接使用 g；noised 和 pred 用 `t_d_p` 构造带噪 latent `z = t_d_p * g + (1 - t_d_p) * epsilon_dino`。

- **`--condition_mode_pixel clean`** 直接注入归一化的 clean patch tokens。
- **`--condition_mode_pixel noised`** 把 `z` 展平为 `[B,256,768]` 后直接注入。Pixel 条件为 `E_p(t_p) + E_y(y) + W_g(z)`。训练时的轻噪声用来模拟采样 grounding 的误差。
- **`--condition_mode_pixel pred`** 用冻结 DinoDiT 做一次 `g_hat = dino_net(z, t_d_p, y)`，再展平预测结果并注入。Pixel 条件为 `E_p(t_p) + E_y(y) + W_g(g_hat)`。

三种模式都只计算 Pixel velocity loss。类别 dropout 同时屏蔽 grounding。采样都先用 DinoDiT 从纯噪声多步生成 latent，再以该 latent 的 tokens 作为 Pixel JiT 的 grounding 生成 RGB。`noised` 模式的 Stage 2 仍加载同一份 Stage 1 checkpoint，供采样使用。可分别设置 `--cfg_dino` 和 `--cfg_pixel`，以及 `--noise_scale_dino` 和 `--noise_scale_pixel`。

## 实验目录

Stage 1 使用 `stage1-{encoder}-{dino_model}-e{epochs}`。Stage 2 用实际加载的 Stage 1 checkpoint 轮数作前缀，再拼接 `stage2-pixeljit-{size}-dinodit-{clean|noised|pred}-e{epochs}`。

```text
checkpoints/stage1-dinov3b-dinodit-b-e80
checkpoints/stage1-dinov3b-dinodit-b-e160
checkpoints/stage1-dinov3b-dinodit-b-e80-stage2-pixeljit-b-dinodit-pred-e200
checkpoints/stage1-dinov3b-dinodit-b-e80-stage2-pixeljit-b-dinodit-noised-e200
```

运行命令、续训和资源路径见 [README.md](README.md)。
