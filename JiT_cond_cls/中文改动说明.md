# JiT-B + DINOv3 CLS block-level AdaLN 消融说明

本文说明 `jit_cond_cls/` 相对于 `JiT_cond/` 的条件粒度变化。这里的实验使用干净图像的 DINOv3-B/16 **CLS token**，通过每个 Transformer block 的全局 AdaLN 注入语义，而不是使用逐 patch token。

## 1. 条件构成

原始 JiT 和本实现的时间、类别条件都是每个样本一个向量：

```text
t_emb = TimestepEmbedder(t)       # [B, D]
y_emb = LabelEmbedder(y)          # [B, D]
```

`grounding.py` 从 clean image 的 `forward_features` 输出中取经过最终 norm 的 `x_norm_clstoken`，形状为 `[B,768]`。新增的 `grounding_proj = Linear(768,768)` 将它投影到 JiT hidden size：

```text
g[b] = W_g(dino_cls[b])            # [B,D]
c[b] = t_emb[b] + y_emb[b] + g[b]  # [B,D]
```

DINOv3 始终处于 eval 且 `requires_grad=False`，提取过程使用 `no_grad`。`W_g` 零初始化，因此初始模型与不带 grounding 的 baseline 数值一致。

## 2. 为什么是 block-level，而不是 patch-level

每个 `JiTBlock` 保留自己的 `Linear(D,6D)`，从 `c[b]` 生成 attention 和 FFN 的 shift、scale、residual gate。`modulate` 把这些 `[B,D]` 参数扩展为 `[B,1,D]`，广播到该样本的全部 token。

因此：

- 不同 block 有各自独立的 AdaLN 参数；
- 同一个样本在一个 block 内的所有 image token 和 in-context token 共用该 block 的调制参数；
- `FinalLayer` 也使用同一个全局 `c[b]` 生成输出前的 shift/scale；
- 不再构造 `JiT_cond` 中的 `c_patch[b,n]`，也不需要 DINO/JiT patch 网格对齐或插值。

这就是本实验所称的 **block-level（全局）AdaLN grounding**。

## 3. 训练路径

`denoiser.py` 保持原始 flow/noise 路径。模型输入是加噪后的 `z`，但 grounding CLS token 来自同一个样本的 clean target image，而不是 noisy state。

训练只优化 JiT 和 `grounding_proj`。新增可训练参数量为：

```text
768 × 768 + 768 = 590,592 ≈ 0.591M
```

DINOv3 不参与优化器或 EMA；checkpoint 的模型字典保留冻结权重以便恢复，EMA 字典只保存可训练参数。

## 4. Label dropout、grounding dropout 与 CFG

Label 被丢弃的样本同时关闭 CLS 语义条件，使其退回真正的 `t + null_label` 路径，避免干净图像的类别信息泄漏到 CFG 无条件分支。

`ground_drop_prob` 可以在保留 label 的同时额外关闭部分样本的语义条件，用于训练 `grounding_source=probe` 所需的纯 `t+y` 路径。当前验证集真实语义上限实验默认 `ground_drop_prob=0`。

采样时：

- `val`：从同类验证集真实图像提取 CLS token，是默认上限设定；
- `probe`：先由纯 `t+y` 路径估计 clean image，再提取 CLS token；
- `none`：不使用语义 token，作为原始 JiT 对照。

CFG conditional 分支使用 CLS grounding；unconditional 分支通过 `grounding_mask=False` 关闭语义，与训练时的 null 路径一致。

## 5. 默认实验与恢复

默认训练为 JiT-B/16、256px、600 epoch、GPU2 八卡、全局 batch 1024。实验名和输出目录为：

```text
JiT-B16-DINOv3B-CLS-BlockAdaLN-ValGrounding-B600
jit_cond_cls/checkpoints/JiT-B16-DINOv3B-CLS-BlockAdaLN-ValGrounding-B600/
```

由于新增 `grounding_proj`，原生 JiT 或 `JiT_cond` checkpoint 不能直接作为完全匹配权重加载；应从头训练，或从兼容的 `jit_cond_cls` checkpoint 恢复。
