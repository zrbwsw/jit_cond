# jit_cond_dino_two_stage_1122_partial

**Partial Trajectory Sampling：在线计算版本（第一版保守参数）**

从 `jit_cond_dino_two_stage_1122_ddim_recon_noflip_pred_drop` 修改而来，新增 `partial_trajectory` 条件模式。训练时从随机 `t_part ~ U[0.6, 1.0]`（均值 0.8）的部分加噪 clean latent 出发，走 5 步 DinoDiT Heun 到 t=1.0，`t_tag = t_part` 告诉模型语义可信度。

---

## 核心设计（第一版）

### 训练时

```python
z_clean = encode_grounding(x_i)
t_part = 0.6 + 0.4 * rand()                               # U[0.6, 1.0]，均值 0.8
z_start = t_part * z_clean + (1 - t_part) * randn()      # 部分加噪
z_cond = DinoDiT_partial_heun(z_start, t_part → 1.0, label, steps=5, CFG=2.0)

# 完整条件传给 Pixel JiT
c = (y, t_pixel, t_tag=t_part, z_cond)
```

### 推理时

```python
z_0 = randn()
z_cond = DinoDiT_heun(z_0, 0 → 1.0, label, steps=25, CFG=2.0)
c = (y, t_pixel, t_tag=1.0, z_cond)  # 推理时 t_tag 固定为 1
```

### 关键设计点

1. **t_part 随机化**：每个样本独立采样 `U[0.6, 1.0]`，让模型见过不同起始点的语义质量
2. **t_tag = t_part**：告诉模型"这份语义从 t_part 出发"，t_tag 越小表示经历更长采样路径、累积误差更多
3. **步数保守**：5 步 Heun，训练 iter time 预计 ~0.42s（pred 0.37s + 10 次 DinoDiT 前向）
4. **均值偏高**：`t_part` 均值 0.8，更接近 clean 端，降低训练难度和开销

### 与 noised 的对比

| 方面 | noised | partial (第一版) |
|-----|--------|------------------|
| 训练条件 | `t_d_p * z_clean + (1-t_d_p) * 高斯噪声`，t_d_p ~ U[0.75, 1) | `t_part * z_clean + (1-t_part) * 高斯噪声 → 5步Heun`，t_part ~ U[0.6, 1.0] |
| t_tag | t_d_p（终点离 clean 的距离） | t_part（起点位置） |
| 语义生成方式 | 直接加噪（不经过 DinoDiT） | 走真实 DinoDiT 采样路径后半段 |
| 实例信息 | 高（平均保留 87.5%） | 高（平均保留 80%） |
| 采样逼真度 | 低（高斯噪声 ≠ DinoDiT 误差） | 中高（真实 5 步轨迹） |

## 参数说明

| 参数 | 默认值 | 说明 |
|-----|--------|------|
| `--steps_part` | 5 | 从 t_part 到 1.0 的 Heun 步数 |
| `--t_part` | 0.8（废弃） | 训练时代码内随机采样 U[0.6, 1.0]，此参数不使用 |

**训练时 t_part 分布**：硬编码为 `0.6 + 0.4 * torch.rand(B)`
- 最小值 0.6：保留 60% 实例信息，走 5 步到 clean
- 最大值 1.0：完全 clean，0 步（退化为 clean bypass）
- 均值 0.8：保留 80% 实例信息，走 5 步

**为什么不用更小的 t_part**：
- t_part 越小，起点越噪，需要走更多步才能到 clean
- 5 步固定时，从 0.4 出发可能不够，输出质量下降
- 第一版保守选 [0.6, 1.0]，确保 5 步足够

## 训练开销分析

### 每个 iter 的 DinoDiT 前向次数

| 模式 | 前向次数/iter | 说明 |
|------|--------------|------|
| `pred` | 2 | 一步预测 × CFG |
| `noised` | 0 | 不调用 dino_net |
| `partial (steps=5)` | **10** | 5 步 Heun × CFG |
| `partial (steps=10)` | 20 | 10 步 Heun × CFG |

### 预估 iter time（batch=128/卡，8 卡）

- **pred**：0.37s（基线）
- **partial (steps=5)**：0.37 + 10 × 0.005 ≈ **0.42s**（1.14× pred）
- **partial (steps=10)**：0.37 + 20 × 0.005 ≈ 0.47s（1.27× pred）

**结论**：5 步版本训练开销可接受，比 pred 慢 ~14%，远快于旧版 cached_recon 的 1.22s。

## 与现有方案的对比

| 方案 | E_D/E_P | Pixel CFG | FID | t_tag 设计 | 训练 iter time |
|------|---------|-----------|-----|-----------|---------------|
| pred（原版） | 160/160 | 2.1 | 4.71 | 固定 1.0 | 0.37s |
| noised | 160/160 | 2.1 | 4.88 | t_d_p（终点离 clean 距离） | 0.35s |
| **partial (第一版)** | **160/160** | **2.1** | **~4.5** | **t_part（起点位置）** | **~0.42s** |

**核心创新**：
1. **t_tag 对齐**：与 noised 一样用时间标量告诉模型语义可信度，但语义来自真实 DinoDiT 路径
2. **实例+采样平衡**：从真实 latent 出发（保留实例），走真实路径（模拟采样误差）
3. **训练灵活**：t_part 随机化，模型学会适应不同质量的语义

**如果第一版 FID 达到 4.5 以下**，说明 partial trajectory + t_tag 设计有效，可以作为后续优化的基线。
