# 无翻转版：训练同时支持实例重建与生成的 DinoDiT

目录 `jit_cond_dino_two_stage_1122_ddim_recon_noflip/`。这一版从随机初始化的 DinoDiT 开始训练，使用预训练且冻结的 DINO 图像编码器定义目标特征。Stage 1 的每次优化都包含生成用的流匹配损失和同图监督的重建损失。Stage 2 默认训练 `cached_recon`，采样沿用类别条件下的两阶段自由生成。

## 从训练到采样

以下命令从本目录运行。训练启动脚本默认在本机可见的 8 张 GPU 上运行；可用 `CUDA_VISIBLE_DEVICES` 指定设备。数据按 ImageFolder 的 `train/<synset>/...` 和 `val/<synset>/...` 排列，两者使用相同类别目录映射。

```bash
export IMAGENET_ROOT=/path/to/imagenet
export PRETRAIN_MODELS_ROOT=/path/to/pretrain_models
export DINOV3_REPO=/path/to/dinov3
export STAT=/path/to/dinov3b_rae_imagenet1k_stats.pt
export S1=checkpoints/stage1-dino-recon-noflip
export S2=checkpoints/stage2-pixel-recon-noflip

# 1. 从头训练 DinoDiT；每 20 个完整 epoch 评估 val 的全部 50,000 张。
bash sh/train_dino.sh --epochs 80 --output_dir "$S1" --dino_stat_path "$STAT" \
  --recon_weight 0.1 --recon_train_steps 4 --recon_train_batch 2 \
  --recon_eval_freq 20 --recon_eval_batch 8 --steps_dino 25

# 2. 对照 val 日志和生成质量选择 checkpoint。这里仅示例第 80 轮。
export CKPT="$S1/checkpoint-80.pth"
export CACHE=/path/to/cache/noflip-e80-ema1-k25
python -m stage1.export_recon --dino_checkpoint "$CKPT" --dino_weights ema1 \
  --dino_stat_path "$STAT" --cache_dir "$CACHE" --split train \
  --batch_size 8 --steps_dino 25 --cfg_dino 1

# 3. 缓存重建 CFG=1 由 cache_cfg_dino 校验；自由采样的 DINO CFG=2 独立设置。
bash sh/train_pixel.sh --epochs 200 --output_dir "$S2" --dino_stat_path "$STAT" \
  --dino_checkpoint "$CKPT" --dino_weights ema1 --grounding_cache "$CACHE" \
  --condition_mode_pixel cached_recon --steps_dino 25 --cache_cfg_dino 1 --cfg_dino 2

# 4. 自由采样只需 Stage 2 checkpoint 和模型资源。
bash sh/sample_pixel.sh --checkpoint "$S2/checkpoint-200.pth" \
  --dino_stat_path "$STAT" --steps_dino 25 --cfg_dino 2 --cfg_pixel 2.9
```

## Stage 1 的两项监督

记 `g_i=E(x_i)` 为冻结 DINO 编码器、去 affine 末层归一化及匹配 latent 统计后得到的特征。默认张量为 `[B,768,16,16]`，空间位置与中心裁剪一一对应。DinoDiT-B 输出 clean latent，两个目标共享全部 DinoDiT 参数。

| 项目 | 输入、目标与梯度 |
|---|---|
| 全 batch 流匹配 | 对每个样本独立采 `e ~ N(0,σ²I)` 和 `t ~ sigmoid(N(-1.2,1²))`。令 `z=t g+(1−t)e`，训练 `mean(((Dθ(z,t,y_drop)−g)/max(1−t,0.05))²)`。类别丢弃仅用于这个分支。它提供自由生成所需的独立高斯先验监督。 |
| 实例重建 | 从每个 rank 已随机打乱的本地 batch 取前 `m=min(B,recon_train_batch)` 张。对每张图以真实类别，用慢速 EMA1 对它自己的 `g_i` 反演得到 `u_i`；停止对反演求导。以 `u_i` 为初态，用当前学生参数正向积分得到 `g_rec_i`，和同一个 `g_i` 逐位置、逐通道计算 MSE。完整学生解码轨迹参与反传。 |
| 合计 | `L = loss_scale_dino × L_FM + recon_weight × L_rec`，默认权重为 1 和 0.1。每个优化步结束后更新 EMA。teacher 与 student 在重建分支上都关闭 dropout；冻结编码器始终以 eval 模式工作。 |

```python
# DinoDenoiser.forward 中的计算关系，伪代码
g = frozen_encoder(center_crop_rgb)
loss_fm = flow_loss(dino_net, g, y)
g_subset, labels = g[:m], y[:m]
with no_grad():
    u = invert(ema1_dino_net, g_subset, labels, steps=4)
rec = decode(dino_net, u, labels, steps=4)      # 这里保留梯度
loss_rec = mean((rec - g_subset) ** 2)
(loss_scale_dino * loss_fm + recon_weight * loss_rec).backward()
```

反演仍采用 DDIM 启发的确定性双向 ODE，t=0 为噪声，t=1 为干净端。倒走第一步在内部网格点估计末端速度，正走最后一步用 Euler，其余默认 Heun。`recon_train_steps=4` 用较粗网格控制显存和反传成本；验证、全量导出和自由生成默认用 `steps_dino=25`。两套步数可分别调整，但不同步数得到的重建 MSE 不能直接当作同一条曲线。默认生成噪声尺度为 1，Stage 1 的 x-pred head、时间采样及加噪路径都可直接用于两个任务。

训练有两类可调开销。增大 `recon_train_batch` 可减少重建监督的样本方差。增大 `recon_train_steps` 可让训练轨迹接近部署轨迹，也增加需要保存激活的前向次数。默认 Heun/CFG=1 时，每个被选中的实例额外经历 7 次无梯度 teacher 前向和 7 次可微 student 前向。降低训练重建误差时，同时测独立 Gaussian 的生成质量；恒等速度流也可能给出很小的往返误差。这里的 0.1 是实验起点，具体可接受的误差由数据和下游质量决定。

## 看训练日志与全量验证

| 位置 | 指标与口径 |
|---|---|
| Stage 1 训练控制台、TensorBoard | `loss_dino` 是原始 v-loss，`recon_mse` 是同图 teacher 反演 → student 解码的未加权 MSE，`loss` 是二者加权和。TensorBoard 键为 `train_loss_dino`、`train_recon_mse`、`train_loss`，默认每 100 个迭代记录一次，跨 rank 取平均。 |
| Stage 1 验证控制台、TensorBoard | 在第 20、40、60、80… 个完整 epoch，用当时的 EMA1 同时执行反演和解码，计算 `val_recon/mse`、`val_recon/relative_l2`、`val_recon/patch_cosine` 和 `val_recon/images`。前两项越低、cosine 越高表示特征重建越接近原图。 |
| checkpoint 目录 | 每次验证生成 `val-recon-e0020.json` 等文件，记录 epoch、实际图数、权重分支、solver、步数、CFG 和指标。默认同时保存编号 checkpoint，便于按轮次配对。可用 `tensorboard --logdir "$S1"` 查看曲线。 |

验证按路径确定性裁剪，遍历完整验证集。每个样本的 MSE 在 `C,H,W` 上平均，相对 L2 是该样本的 `||rec−g||₂/||g||₂`（分母设数值下限），patch cosine 先在通道维计算，再平均空间位置。各 rank 以步长 world size 分配索引，各自处理最后不足一批的图，将指标总和和实际计数做 all-reduce，再除以全局图数。因此不需要在不足整批的位置重复或丢弃图片。验证使用无梯度 FP32 模型前向，与缓存导出时的特征定义一致；导出最后写盘前另转 FP16。

验证输出是 DINO 特征域的误差。实际运行会重建每张 val 图的特征并流式统计，磁盘存储的是汇总结果。若要落盘 val 特征，用上面的导出命令改为 `--split val` 并指定独立目录。默认要求验证集恰有 50,000 张，且类别映射与 train 匹配。小规模连通性验证可用一个单独的数据根，显式给 `--recon_val_expected 实际数量 --recon_eval_freq 1`。默认每张验证图需要 98 次 DinoDiT 前向，吞吐和 GPU 内存应先实测，可调 `--recon_eval_batch`。续训沿用相同的优化配置并传 `--resume "$S1/checkpoint-last.pth"`，评估按已完成的全局 epoch 接续。

## Stage 2 按图取条件

所有训练图、验证图和离线导出图均用同一 ADM 中心裁剪，整个版本关闭水平翻转。每个 ImageFolder 样本只有一个对应缓存项。去掉翻转仅去掉了方向选择；每张图对应哪一行仍由扫描得到的相对路径和标签确定，训练 shuffle 只改变读取顺序。结论适用于这个实验设置，增强对最终 FID 的影响可用同预算对照测量。

训练默认 `cached_recon`。读取 `g_rec_i` 后传入 `[B,256,768]` 空间 tokens，条件为 `E_p(t_p)+E_y(y)+E_d(1)+W_g(g_rec_i)`。Pixel 的类别 dropout 同时屏蔽 grounding，训练目标仍为 RGB 的 v-loss。自由采样时先用 Stage 1 从独立高斯生成 `g_new`，再从独立像素噪声出发，以 `g_new` 和相同终点标签 1 调制 Pixel JiT。原有 `pred`、`noised` 可显式选择作对照。

缓存 schema v2 的 NPY 分片是 FP16、形状 `[rows,256,768]`。每张图约 384 KiB，128 万张约 469 GiB。清单验证数据索引、teacher 实际权重、latent 统计和求解设置。旧版带 view 轴的缓存需要重新导出；替换图片、重新训练 teacher 或改归一化统计时请使用新缓存目录。Stage 1 初始化无需旧 DinoDiT checkpoint，仍需提供冻结图像编码器权重及匹配的统计文件。

## 代码入口

| 文件 | 本版负责的逻辑 |
|---|---|
| `stage1/denoiser_dino.py` | `instance_reconstruction_loss` 实现代入 EMA 参数的反演与可微学生解码；`forward` 组合两项监督；`sample_dino_latent` 用独立噪声复用正向积分器。 |
| `stage1/main_dino.py`、`stage1/eval_recon.py` | 训练参数、评估周期、完整 val 分片、EMA 验证、控制台/TensorBoard/JSON 日志。 |
| `util/training.py`、`stage1/export_recon.py`、`util/recon_cache.py` | 确定性图像变换、每图单份缓存、分片恢复和按索引读取。 |
| `main_jit.py`、`denoiser.py`、`checkpoint_io.py` | Stage 2 默认使用缓存训练、两阶段采样、恢复时校验 Stage 1 损失参数或 Stage 2 缓存身份。 |

选择模型时先比较相同 EMA、相同步数下的全验证集指标，再比较从独立先验生成的特征分布和 Stage 2 的 FID。可固定类别与像素噪声，只替换同类两张图片的缓存条件，比较生成结果重新编码后与各自条件的 patch cosine，以检查 Pixel JiT 是否使用了实例布局。
