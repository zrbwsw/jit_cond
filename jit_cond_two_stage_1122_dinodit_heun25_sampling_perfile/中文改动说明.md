# jit_cond_two_stage_1122_dinodit_heun25_sampling_perfile

**Cache version 4: 训练与推理完全一致的自由采样条件**

从 `jit_cond_dino_two_stage_1122_ddim_recon_noflip_perfile` 修改而来，核心改动：将 Stage 2 训练条件从"重建特征"换成"自由采样特征"，彻底消除 train-test gap。

---

## 核心设计思想

| 条件模式 | 训练条件来源 | 推理条件来源 | Train-Test Gap |
|---------|-------------|-------------|----------------|
| `noised` | U[0.75,1) 高斯噪声 | DinoDiT 25步采样 | 高斯 ≠ 积分误差 |
| `pred` | DinoDiT 一步预测 | DinoDiT 25步采样 | 一步 ≠ 25步 |
| `cached_recon` (v3) | 重建特征（含实例锚点） | 自由采样特征 | 重建 ≠ 采样 |
| **`cached_sampling` (v4)** | **DinoDiT 25步采样** | **DinoDiT 25步采样** | **无 gap** |

**预期收益**：FID 应优于 pred 的 4.71，逼近甚至超过 noised clean-bypass 的 3.45（因为训练权重也在采样分布上训练）。

## 使用方法

### 1. 导出自由采样 cache（version 4）

```bash
cd /data0/zhangruobei/Work/jit_cond_ablation/jit_cond_two_stage_1122_dinodit_heun25_sampling_perfile

# 复用已有 DinoDiT E160 EMA1 checkpoint
DINO_CHECKPOINT=../jit_cond_dino_two_stage_1122/checkpoints/stage1-dinov3b-dinodit-b-e160/checkpoint-160.pth \
CACHE_DIR=/path/to/cache/e160-heun25-cfg2-sampling \
CFG_DINO=2.0 SEED_BASE=42 \
bash sh/export_recon_perfile.sh
```

**参数说明**：
- `CFG_DINO=2.0`：与推理时一致，表 3 用的是 `D_heun25 2.0;[0,1]`
- `SEED_BASE=42`：每张图的实际种子 = 42 + 全局索引，确保可复现
- 导出时间：128 万张 × 25步 Heun，8 卡约 X 小时（需实测）

### 2. Stage 2 训练

```bash
bash sh/train_pixel.sh \
    --condition_mode_pixel cached_sampling \
    --grounding_cache /path/to/cache/e160-heun25-cfg2-sampling \
    --dino_checkpoint <同上 E160 ckpt> --dino_weights ema1 \
    --epochs 160 --batch_size 128
```

训练时不调用 `dino_net`，直接读缓存的采样特征，iter time 应与 `cached_recon` 类似（~0.4s，待验证 perfile I/O 优化后的实际值）。

### 3. 推理

```bash
bash sh/sample_pixel.sh \
    --checkpoint <Stage 2 ckpt> --dino_weights ema1 \
    --steps_dino 25 --cfg_dino 2.0 --cfg_pixel 2.1 \
    --num_images 50000
```

推理路径与训练完全一致：DinoDiT 从 N(0,σ²I) 25步 Heun + CFG 2.0 → Pixel JiT 50步 Heun + CFG 2.1。

## 与其他模式的对比

| 模式 | E_D/E_P | Pixel CFG | FID | 训练条件 | 推理条件 | Gap |
|------|---------|-----------|-----|---------|---------|-----|
| pred (原版) | 160/160 | 2.1 | 4.71 | 一步预测 | 25步采样 | 有 |
| noised | 160/160 | 2.1 | 4.88 | U[0.75,1) 噪声 | 25步采样 | 有 |
| cached_recon (v3) | 80/80 | 2.1 | 5.43 | 重建特征 | 采样特征 | 有 |
| **cached_sampling (v4)** | **160/160** | **2.1** | **待测** | **25步采样** | **25步采样** | **无** |

**理论上界**：noised clean-bypass 3.45（但那是用 noised 权重 + clean token，不是真实可达上界）。真实可达上界是用 cached_sampling 训练的权重 + 推理时采样，预期 **3.5–4.0**。

## 实现细节

### 每图独立种子的必要性

```python
for idx in batch_indices:
    seed = args.seed_base + idx  # 42+0, 42+1, 42+2, ...
    torch.manual_seed(seed)
    z_sampled = model.sample_dino_latent(label)
```

**为什么不能所有图共享一个随机流**：
- 分布式训练时每个 rank 处理交错索引，共享流会导致同一张图在不同运行中拿到不同特征
- 独立种子确保可复现：重跑导出得到完全相同的 cache

### Version 4 manifest 格式

```json
{
  "spec": {
    "version": 4,
    "layout": "per_file_sampling",
    "cfg": 2.0,
    "seed_base": 42,
    ...
  },
  "count": 1281167,
  "id": "<sha256(spec + count)>"
}
```

`cached_dataset` 加载时校验 `version==4` 和 `teacher_hash`，防止误用 v3 重建 cache。
