# DINO DiT 指定样本重建与两阶段生成修改指南

适用版本为 `jit_cond_dino_two_stage_1122_ddim_recon`。原始基线锁定在 [zrbwsw/jit_cond · 693ab3b](https://github.com/zrbwsw/jit_cond/tree/693ab3baa8d5331974d6e2311f1fe8194df13d18/jit_cond_dino_two_stage_1122)。下文的文件名均相对于新目录。

**建议先用已有 Stage 1 EMA1 做反演。** 对图片 A，冻结 encoder 得到归一化 patch 特征 `g_A`。沿同一个类别条件速度场倒走得到 `u_A`，再从 `u_A` 正向积分得到 `g_rec,A`。Stage 2 每次读取 A 的同一裁剪视图对应的 `g_rec,A`。自由生成时把起点换成独立高斯噪声，使用同一个正向积分器生成新的 grounding，再用独立像素噪声生成图像。导出对象是 DINO 特征；恢复给定 RGB 的像素细节还取决于 Pixel 模型和像素初态。

## 1. 原代码训练了什么

| 链路 | 文件与函数 | 行为和实现含义 |
|---|---|---|
| 图像到 latent | `util/training.py::make_train_loader`、`util/train_epoch.py::train_one_epoch`、`DinoLatentModel.encode_grounding` | ImageFolder 的 train 子目录，ADM 中心裁剪、随机水平翻转、PILToTensor。CPU 输出 uint8，训练循环转为 RGB [-1,1]，encode_grounding 再映到 [0,1]。直接调用时必须遵守这个值域。 |
| 特征定义 | `stage1/dinov2_encoder.py::DINOLatentEncoder.encode` | DINOv3-B/16 输入 256²，取 `x_norm_patchtokens`。v2-reg-B/14 将画面缩至 224²，去掉 CLS 和四个 register。两者末层 norm 去 affine，经 encoder 输入标准化及 latent 的 `(z−mean)/sqrt(var+1e−5)`，得到 [B,768,16,16]。缓存这一坐标系，无额外尺度。 |
| Stage 1 网络 | `stage1/dino_dit.py::DinoDiT.forward`、`stage1/lf_modules.py` | patch=1 的 768→128→768 投影，二维位置编码、RoPE，12 层、12 头，在索引 4 的 block 前插入 32 个类别 token。全局 AdaLN 接收时间和类别，末层输出 clean latent 估计。无需改变输入通道或增设重建 head。 |
| Stage 1 训练 | `stage1/main_dino.py::main`、`stage1/denoiser_dino.py::DinoDenoiser.forward` | 冻结 encoder，训练 dino_net，默认 80 epochs，label dropout 0.1，维护两组 EMA。每个带噪输入都以构造它的同一张图的 clean latent 为监督。 |
| Stage 1 生成 | `DinoLatentModel.sample_dino_latent`、`_velocity_dino`、`_step_dino` | 从 scaled Gaussian 出发，默认 25 个均匀区间。Heun 在最后一区间改用 Euler，避免正向在 1 求速度。CFG=1 直接使用有类分支，其他值按区间混合条件和空类别速度。 |
| Stage 2 在线条件 | `denoiser.py::Denoiser.prepare_grounding_pixel` | `noised` 给本图带噪特征及其时间标签，`pred` 把同一带噪特征和真实类别送给冻结 DinoDiT 一次，以 clean 候选和 tag=1 做训练。两者都有实例信息，和多步往返的误差来源不同。 |
| Stage 2 条件注入 | `model_jit.py::JiT.forward/_prepare_grounding`、`JiTBlock.forward` | 默认 /16 的 256 个像素 patch 与 DINO 网格对应。条件 patch i 为 `E_p(t_p)+E_y(y)+E_d(tag)+W_g(g_i)`，prefix 只取全局部分。grounding_proj 零初始化，网格不同则双线性插值。类别 dropout 同时屏蔽语义投影与 DINO 时间嵌入。 |
| Stage 2 采样 | `Denoiser.generate`、`engine_jit.evaluate` | generate(labels) 先采一个 DINO 场，再在固定 grounding、tag=1 下积分 RGB。可显式传 `grounding_tokens` 做指定条件实验。默认像素 50 步 Heun、CFG 2.9、区间 (0.1,1)，评估使用 Pixel EMA1。 |

三个时间变量应分别记录。`t_d` 是 Stage 1 训练时间，默认 `sigmoid(N(-1.2,1²))`。`t_d_p` 控制 Stage 2 在线条件的腐蚀，默认 `U[0.75,1)`，也可用 Stage 1 的 logit-normal。`t_p` 是独立的 RGB 训练时间，默认 `sigmoid(N(-0.8,0.8²))`。`cached_recon` 读出的已是正向积分终点，所以传给 Pixel 的 `t_dino=1`，跳过 `t_d_p`；RGB 的时间抽样、噪声和 v-loss 仍适用。[原始条件实现](https://github.com/zrbwsw/jit_cond/blob/693ab3baa8d5331974d6e2311f1fe8194df13d18/jit_cond_dino_two_stage_1122/denoiser.py#L33-L93)

## 2. DDIM 的哪一步能迁移

DDIM 的确定性采样（η=0）允许沿给定模型轨迹编码和解码。这里迁移的是“同一确定性条件流可以双向积分”。本仓库使用直线插值，方向定义为 0 噪声、1 数据。若引入 VP 的 `alpha_bar`、beta 表或离散 DDPM 噪声预测公式，就改变了已有权重所对应的训练路径。依据见 [DDIM](https://arxiv.org/abs/2010.02502)、[Rectified Flow](https://arxiv.org/abs/2209.03003) 和 [JiT](https://arxiv.org/abs/2511.13720)。

令 `e=σξ, ξ~N(0,I)`、`z_t=t g+(1−t)e`，网络输出 `Dθ(z_t,t,y)`。实现的速度与损失为

```text
d(t)   = max(1−t, t_eps)                 # 默认 t_eps = 0.05
v_pred = (Dθ − z_t) / d(t)
v_tgt  = (g  − z_t) / d(t)
L_FM   = loss_scale_dino × mean[(Dθ − g)² / d(t)²]
```

在 `1−t ≥ t_eps` 时，`v_tgt=g−e`。在 clamp 区，target 与 prediction 都用相同的截断分母，等价 clean MSE 权重最高为 400。对于未截断的内点，还可以用 `e_hat=(z_t−t·Dθ)/(1−t)` 推出 `z_s=s·Dθ+(1−s)·e_hat=z_t+(s−t)·v_pred`，这就是该直线路径的一步确定性 Euler 更新。Heun 再估计一次速度校正曲率。每步重新预测，不能假设单点估出来的 e_hat 就等于整条轨迹的反演码。[原始训练与求解器](https://github.com/zrbwsw/jit_cond/blob/693ab3baa8d5331974d6e2311f1fe8194df13d18/jit_cond_dino_two_stage_1122/stage1/denoiser_dino.py#L67-L128)

**实例信息来自反演的输入。** 对固定 y，独立抽的 e 与给定 g 条件独立。在 t=0 处用随机 e 强行回归指定样本，平方损失的最优解是类条件均值。反演从 g_A 本身开始，得到的是模型给 A 的隐码 u_A。它与 g_A 有关，量纲已经包含 σ，解码时直接传入。图像 A 原先训练中随机抽过的噪声无需保存。

**端点选择。** 原实现用 clamp，因此 t=1 计算上有界，但训练抽样几乎没有覆盖端点，clamp 也改变了末段的场。新实现取 h=1/K，从 g 开始，用 `g−h·v(g,1−h,y)` 估计倒数第二个节点，后续按同一网格、负步长做 Euler/Heun。第一步是对原正向末步的单次近似回代，速度的状态参数有近似误差。显式 Heun 倒走也只是近似逆。用 K=25/50/100 测误差和耗时，步长为 1/K，避免用 K=1 判断实例能力。若末端误差主导，可在小样本上求解 `w+h·v(w,1−h)=g` 并报告残差和失败率；该离散映射可能病态。时间网格、CFG、类别、权重和精度都应在双向保持一致。

```python
# net.eval()，使用已加载的同一组 teacher 权重
g = model.encode_grounding(x_minus1_plus1)     # [B,768,16,16]
u = model.invert_dino_latent(g, y)             # 不抽新噪声
g_rec = model.decode_dino_latent(u, y)
cache_tokens = model._as_tokens(g_rec)         # [B,256,768]，先 H 后 W
g_new = model.sample_dino_latent(y)            # 新实例，自带 σ·randn
```

## 3. 何时改 Stage 1 训练

| 路线 | 使用条件 | 实验设计和代价 |
|---|---|---|
| 已实现：原训练 + 离线双向 ODE | 有能生成 DINO 特征的 checkpoint | 保留 x-pred、v-loss、独立高斯、logit-normal、类别 dropout。先比较可复用的 EMA1、EMA2 和 model。生成质量与实例重建各自验收。 |
| 有限噪声的一步或多步恢复 | 缓存算力受限，或需要带受控扰动的配对条件 | 取 t=0.25/0.5/0.75，以固定的每图种子构造 z_t，比较 Dθ 一步与 t→1 积分。较高 t 留下较多本图信息。它可以仿真条件误差，生成起点分布仍需另测。现有 pred 是这组便宜的基线。 |
| 可选：带实例监督的微调 | 固定计算预算下验证集的恢复或同类检索落后，且生成基线已测 | 用冻结 EMA teacher 对真实 g 反演得到停止梯度的 u，在少量 minibatch 上让 student 展开 K' 步，优化 `L_FM + λ·mean((F_student(u,y)−g)²)`。固定 teacher 周期，保留独立高斯 FM batch，先扫 λ=0 和小权重，比较相同训练 FLOPs。student 的积分须启用梯度；现有推理 helper 有 no_grad，需另写可微正向。显存紧时只训练最后几步，记录截断位置。 |
| 可选：学习 inverse encoder 或逐样本优化 u | 反演导出耗时成为瓶颈，或少数样本误差特别大 | 可蒸馏 `Iφ(g,y)≈u_teacher`，再加冻结 decoder 的终点损失。若联合训练，监控聚合隐码对高斯的偏离和随机先验生成质量。逐图优化只宜作为小集重建参考，要单列迭代数，避免把拟合能力归给原 checkpoint。 |

训练时可以每个保存点对固定 val 子集做反演和随机生成，指标用来选 checkpoint，导出只对选中的不可变文件做一次。单独优化同一速度场的往返 MSE 会给近恒等场很好的分数。对训练调度的修改应由分桶误差驱动；例如高 t 端不足时，尝试少量中高 t 混合采样，同时匹配优化步数并测低 t 生成。改变时间抽样会改变目标的期望权重。先在同一 ckpt 比较积分网格，单独报告 NFE，再决定是否重训。改变 σ、latent 统计、clamp 或路径时，给模型和缓存另开版本。像素侧的 t_p 分布不能补偿 Stage 1 的先验偏移。

## 4. 可执行的导出与训练

在新目录下运行。`CKPT` 指向已完成的 Stage 1 权重，`IMAGENET_ROOT` 含 train/、val/，类别子目录与原训练一致。按原项目提供 DINO 权重、源码与 latent stat；非默认 encoder、σ、t_eps 等使用原权重的实参。现版导出器每次用单进程单设备，以分片为断点。第一次验证可另建一个小型 ImageFolder 根并用独立 cache_dir 做完整往返。

```bash
export CKPT=/path/to/checkpoint-80.pth
export IMAGENET_ROOT=/path/to/imagenet
export CACHE=/path/to/cache/e80-ema1-k25-center
python -m stage1.export_recon --dino_checkpoint "$CKPT" --dino_weights ema1 \
  --data_path "$IMAGENET_ROOT" --split train --cache_dir "$CACHE" \
  --steps_dino 25 --cfg_dino 1 --views 1 --batch_size 8 --shard_size 128

bash sh/train_pixel.sh --dino_checkpoint "$CKPT" --dino_weights ema1 \
  --condition_mode_pixel cached_recon --grounding_cache "$CACHE" \
  --steps_dino 25 --cfg_dino 1 --output_dir checkpoints/pixel-e80-recon-center

bash sh/sample_pixel.sh --checkpoint checkpoints/pixel-e80-recon-center/checkpoint-last.pth \
  --steps_dino 25 --cfg_dino 1 --cfg_pixel 2.9
```

为公平比较 `pred` 与缓存版，可用 `--views 2` 另导一份。view 0 为中心裁剪，view 1 为其像素水平翻转后重新编码、反演和解码。两视图运行训练时在 Dataset 内只抽一次 view；单视图训练固定中心裁剪。直接把原图 token 网格左右翻转无法保证等于对翻转图的 DINO 提取。若增加随机裁剪、颜色或尺度增强，要明确视图并重新配对。Stage 2 使用缓存只省每次训练的 encoder 和 teacher 前向，构造模型、读取 stat 和生成时仍沿用仓库的 teacher 依赖。

续训时传同一 `--condition_mode_pixel cached_recon --grounding_cache "$CACHE"`、积分配置及 `--resume /path/to/pixel_ckpt`，由 Pixel checkpoint 恢复 teacher。采样使用 Stage 2 checkpoint 内嵌的权重，无需缓存。`generate(labels, grounding_tokens=tokens)` 可以单测给定 grounding 的 Pixel 条件遵循程度，显式传入的 token 要与模型在同一设备上。

## 5. 缓存和 checkpoint 的数据契约

- `stage1/export_recon.py::export` 复用 `checkpoint_io.read_checkpoint/load_branch`。先恢复 `model.dino_net.*` 和冻结 encoder，再按选择覆盖 trainable 的命名 EMA 分支，fixed positional 参数取自 model。`resume_model` 则用于同阶段恢复 optimizer、EMA 和 epoch。Stage 2 的 EMA 只有可训练的 Pixel 参数；抽取嵌入的 teacher 应使用其中 `model` 的 dino_net 状态。[原始 checkpoint 实现](https://github.com/zrbwsw/jit_cond/blob/693ab3baa8d5331974d6e2311f1fe8194df13d18/jit_cond_dino_two_stage_1122/checkpoint_io.py#L50-L145)
- `spec.json` 记录 checkpoint 文件 SHA256、实际加载的 dino_net 和 encoder 权重摘要、统计文件 SHA256、类别/路径索引摘要、shape 约定、视图、步数、solver、CFG 区间、σ 和 t_eps。目录允许迁移，ImageFolder 的相对路径、标签、顺序和 `class_to_idx` 要匹配。索引摘要覆盖路径与标签；若原地替换图像内容，应更换数据版本并重建缓存。train 与 val 用独立目录。
- 第 i 个样本对应 `part=i//shard_size`、`row=i%shard_size`，分片为 FP16 NPY，形状 `[rows,views,256,768]`。导出完成前检查写入半精度后的有限性，临时文件完成后替换正式分片。重跑同命令时校验分片 SHA256 并复用。`manifest.json` 最后生成，摘要绑定配方和各分片内容。训练启动核对全部 header，`--verify_cache_hashes` 可做完整内容校验，多 rank 时注意共享盘读带宽。
- `util/recon_cache.py::CachedFolder` 使用内存映射按需取样，worker 内有界缓存，返回 `(uint8_rgb, label, fp16_tokens)`。先依据图像列表取行，再由训练 sampler shuffle，DDP rank、batch 序号和 epoch 均不参与样本 ID。Stage 2 断点保存 `args.cache_id`，读回后校验一致性。训练数据加载共用的 `drop_last=True` 仅影响 epoch 的 minibatch；导出按全索引遍历，末分片保留余数。
- 每图每视图 `256×768×2=393216` 字节（384 KiB）。以 1,281,167 张估算，单视图约 469 GiB，双视图约 939 GiB，另计文件头与校验资料。空间紧张时先做子集，不必全量保存 u。默认 K=25、Heun、CFG=1 时两个方向各 49 次网络评估，共 98 次/视图，另加一次冻结 encoder。先测一片实际 samples/s，再按样本与视图数估算总工时；显存瓶颈可调导出 batch_size。
- 若以后并行化导出，按完整分片分配 `part % world_size`，各 rank 写各自的临时文件；单一协调者验证无缺失、重复及 checksum 后发布清单。当前实现对同输出目录加单写锁，勿用 torchrun 对该目录并发启动。

## 7. 怎样判断值得训练整套 ImageNet

先固定一份训练外验证集，保留每类多个实例。用文件路径和视图固定验证输入，给各实验复用噪声种子。下面四组结果单独记录；每次报告权重分支、步数、CFG、精度、样本量和耗时。

| 要回答的问题 | 建议测量 | 对照与判读 |
|---|---|---|
| 数值往返是否可靠，是否保留 A 的空间布局？ | 在 normalize 后的 g 上算配对 MSE、相对 L2、逐 patch cosine 和误差热图，报告中位数及 P95。用 ĝ_A 在同类真实候选中检索原图，报告 Recall@1 与候选数。 | K=25/50/100，Euler/Heun，比一次 pred、同类错配、打乱 patch、直接保存 clean 的 FP16 量化误差。另用恒零速度场演示往返可完美而随机生成仍是高斯。 |
| 带噪输入上的训练目标是否学好？ | 固定多档内点 t 和同图噪声，比较单步 x-pred 与从该点积分到 1 的误差，同类检索同步记录。 | 分开观察高 t 残留信号与低 t 恢复能力。在 t=0 的独立噪声下转用分布评价，不给任意原图算配对重建分数。 |
| 反演码与生成先验是否兼容？ | 对 `u/σ` 统计通道均值、方差、范数、空间相关、随机投影分布。对真实、重建、独立先验生成三组 latent 分别比较 pooled feature 均值/协方差、类内多样性、最近邻距离和空间 token 统计。 | 用等量真实集两半提供估计噪声参考。相同一、二阶矩不足以证明高维 Gaussian。报告生成与重建分布之间的偏差，它决定 Stage 2 训练和推理的条件差距。 |
| Pixel 是否利用 grounding 且自由生成质量可接受？ | 保持 y、像素噪声相同，依次输入本图 clean/rec、同类另一图的 rec、先验采样特征；比较生成结果重新编码后的 patch cosine 与指定条件的同类检索。固定条件、改变像素噪声看多样性。 | 用相同训练预算比较 pred/noised/cached_recon，控制翻转和 CFG。最终在 `generate(labels)` 下测 FID-50K、IS 与每类覆盖。现有 `engine_jit.evaluate` 用真实图像 FID 统计；特征空间分布指标应另命名。 |

```python
# 验证子集伪代码；固定 y、每个样本的 view，以及运行间的随机源
real = model.encode_grounding(rgb)
inv = model.invert_dino_latent(real, y)
rec = model.decode_dino_latent(inv, y)
gen = model.sample_dino_latent(y)
paired_mse = (rec.float() - real.float()).square().mean((1, 2, 3))
patch_cos = F.cosine_similarity(rec.float(), real.float(), dim=1)
# 按 image ID 聚合，而非把 256 个 patch 当成 256 张独立样本
```
