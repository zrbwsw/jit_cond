# noflip + pred_drop 版本改动说明

在 `jit_cond_dino_two_stage_1122_ddim_recon_noflip` 基础上修复四处问题。

## 修改点

### P1：pred 模式补全 label dropout（`denoiser.py`）

原版 `prepare_grounding_pixel` 在 pred 模式下直接用原始 `labels` 调用冻结 DinoDiT：

```python
z_cond = self.dino_net(z_cond, t_d_p, labels)   # 旧：从不用 null label
```

推理时 DinoDiT CFG 会分别前向有条件和无条件两次，grounding token 分布受 CFG scale 影响。训练时 Pixel 从未见过无条件 DinoDiT token，存在 train-test gap。

修改后：用与 Pixel 侧 label dropout 独立采样的 `labels_for_dino` 调用 DinoDiT，使训练覆盖 DinoDiT 在 null label 下的输出分布：

```python
labels_for_dino, _ = self.drop_labels_with_mask(labels)
z_cond = self.dino_net(z_cond, t_d_p, labels_for_dino)
```

注意：Pixel 侧的 `labels_dropped` 和这里的 `labels_for_dino` 是两次独立 dropout，互不干扰。

### P2：logit_normal 分支使用专属时间参数（`denoiser.py`、`main_jit.py`）

原版 `prepare_grounding_pixel` 的 `logit_normal` 分支复用 Stage 1 参数 `t_mean_dino/t_std_dino`（默认 −1.2/1.0），对应 DinoDiT 训练用的全时间范围分布，与 Stage 2 目标区间 [0.75, 1) 不匹配。

修改后，新增两个独立参数 `--t_mean_dino_pixel`（默认 1.95）和 `--t_std_dino_pixel`（默认 0.5），logit_normal 分支使用这两个值。默认值 logit(0.875)≈1.95 对齐 `U[0.75,1)` 中值，std=0.5 将采样集中在 [0.75, 1) 附近。uniform 分支不受影响。

### P3：resume 校验纳入新参数（`checkpoint_io.py`）

`validate_metadata` 在 pixel resume 路径下新增校验 `t_mean_dino_pixel` 和 `t_std_dino_pixel`，防止续训时参数与初次训练不一致。旧 checkpoint 若缺失这两个键，自动注入与 argparse 默认值相同的值，对旧实验续训透明兼容。

### P4：`_velocity_dino` 无 `@torch.no_grad()` 的原因说明（`stage1/denoiser_dino.py`）

在代码中加注释，说明此处故意不加装饰器，原因是 `instance_reconstruction_loss` 中的 `_decode` 需要在学生解码轨迹上保留梯度。上游调用链（`sample_dino_latent`、`decode_dino_latent`）自身携带 `@torch.no_grad()`，行为正确。与原版 `jit_cond_dino_two_stage_1122` 的差异在此处有文字说明，合并时不要恢复旧装饰器。

## 文件变更清单

| 文件 | 修改内容 |
|---|---|
| `denoiser.py` | P1 pred dropout；P2 新增 `t_mean_dino_pixel`/`t_std_dino_pixel` 属性并在 logit_normal 分支使用 |
| `main_jit.py` | P2 新增 `--t_mean_dino_pixel` 和 `--t_std_dino_pixel` 参数 |
| `checkpoint_io.py` | P3 resume 校验新增两个参数，旧 checkpoint 透明补默认值 |
| `stage1/denoiser_dino.py` | P4 注释说明 `_velocity_dino` 无 `@torch.no_grad()` 的设计意图 |

其余逻辑（Stage 1 重建 MSE、noflip 中心裁剪、cached_recon 缓存路径）与 noflip 版完全相同。
