# JiT：带噪 DINO grounding + PixelDiT2 时间条件 projector

本目录由 `JiT_cond` 单独复制，原目录保留。新版本继续使用 JiT 主干与 patch-level AdaLN，将语义分支改为当前带噪图像经过冻结 DINOv3-B/16 和可训练的 PixelDiT2 时间条件 projector。

## 训练链路

设干净目标为 `x`，采样噪声为 `e`，JiT 时间为 `t∈[0,1]`：

```python
z_t = t * x + (1 - t) * e
raw_tokens = DINOv3_B(z_t)  # 冻结、eval、no_grad
semantic = timestep_projector(raw_tokens, t, grid_hw)
condition = t_embed[:, None, :] + y_embed[:, None, :] + semantic
```

`DINOv3_B` 的输入是与 JiT 相同的 `z_t`，不是干净目标 `x`。训练仍需要真实图像来构造加噪样本和 loss，但 grounding 不接收额外的干净图或缓存的原图特征。`t=0` 对应纯噪声，`t=1` 对应干净图；projector 接原始 `t`，没有时间反转或 1000 倍缩放。

DINO 的预处理保留 PixelDiT2 的方式：`(z_t+1)/2` → ImageNet mean/std 标准化 → 必要时调整输入空间分辨率。噪声值可以超出正常图像范围，因此不做 clamp。输入先对齐 JiT 的 patch 网格，再编码：`B/16 @256` 得到 256 个 DINO token；`B/32 @512` 将 DINO 输入调整到256，同样得到256个 token。

## Projector 与逐 patch 条件

默认 JiT-B/16 采用：

| 项目 | 默认值 |
| --- | --- |
| DINO 输出维度 | 768 |
| projector hidden size | 768，跟随 JiT hidden size |
| projector blocks | 1 |
| projector heads | 12，跟随 JiT num_heads |
| projector 输出维度 | 768，跟随 JiT hidden size |

Projector 结构来自 PixelDiT2：

```text
DINO patch tokens [B,256,768]
  → input_proj
  → timestep-conditioned Transformer block
      RMSNorm → 时间 AdaLN → RoPE attention → gated residual
      RMSNorm → 时间 AdaLN → SwiGLU FFN → gated residual
  → output_proj
  → semantic [B,256,768]
```

它使用独立的时间 embedding 来调制 projector block，因此同时承担带噪 DINO 特征的转换和输出维度映射。旧的 `grounding_proj` 单层 Linear 已被替换，输出后不再叠加第二个旧 projector。

初始化保留 PixelDiT2 的方式：projector block 内六路 AdaLN 的最后一层为零，input/output Linear 保留普通初始化，不把整个语义分支输出清零。初始 block 为 identity residual，开始学习后会逐步产生时间相关变换。JiT 的残差 gate 和输出层仍按原方式零初始化；首步 projector 梯度可能为零，不能据此判断分支被意外 detach。

每个图像 patch 的条件为：

```text
c_patch[b,n,:] = t_embed[b,:] + y_embed[b,:] + semantic[b,n,:]
```

JiT 各 Transformer block 及 final layer 都使用该逐 patch 条件。32 个 in-context token 继续使用 JiT 原来的全局 `t+y` 条件，不将 PixelDiT2 的 context 条件均值策略一并移植，也不额外插入 `SiLU(c)`。DINO 保持冻结，projector 与 JiT 参加反向传播、优化器、EMA 和 checkpoint。

## 采样链路

公开生成入口只需要类别标签。初始状态为随机噪声；每次速度评估都由当前状态生成 grounding：

```text
当前 (z,t)
  → DINO(z)
  → projector(tokens,t)
  → JiT(z,t,y,c_patch)
  → velocity
  → 下一个采样状态
```

Heun 的第二次评估会使用预测得到的 `z_next_euler` 和 `t_next` 重新运行 DINO/projector，不复用当前步或最初噪声的 token。最后一步继续使用 Euler。

采样已移除原图 reference、验证集同类图片 provider 和先估计 clean image 的 probe 路径。生成模式不创建 ImageFolder，不需要 ImageNet 原图；计算 FID/IS 仍需统计文件与 Inception 权重。

CFG 保留参考实现的联合条件策略：训练 label-drop 的样本同时关闭 grounding；采样 conditional 分支使用类别和当前带噪 grounding，unconditional 分支使用 null label 且关闭 grounding。`ground_drop_prob` 默认0，可增加“保留类别、关闭 grounding”的训练样本。

## 启动与 checkpoint

训练脚本默认通过 `run_on_gpu.sh` 转发到 GPU1（`agent-gpu-l2-1`），实验名为 `JiT-B16-DINOv3B-Noisy-PixelDiT2Proj-B80`，训练80个 epoch，并在日志索引 `19、39、59、79` 进行在线评估。先检查命令：

```bash
bash sh/train_jit_b16_grounding_8gpu.sh --dry-run
```

运行：

```bash
bash sh/train_jit_b16_grounding_8gpu.sh
```

采样示例：

```bash
CHECKPOINT=/path/to/checkpoint-last.pth \
  bash sh/sample_jit_b16_grounding_8gpu.sh --dry-run
```

去掉 `--dry-run` 才会执行。新 projector 的参数结构与旧 clean-grounding checkpoint 不兼容，使用新实验目录与新版本 checkpoint；不要把旧实验输出作为默认恢复目录。

默认本地 Python、数据、DINO 和 FID 路径及可覆盖环境变量见 [README.md](README.md) 和 [sh/README.md](sh/README.md)。创建代码不代表已启动完整训练或验证收敛效果。

## 已执行的验证

已完成真实 DINOv3-B 与 JiT-B/16（256×256、batch=1）的四步优化检查，以及两步 Heun 纯噪声采样。Projector 从第三步开始出现非零梯度，20个参数张量更新；冻结的 DINO 未产生梯度。Heun 两步采样按预期进行了三次当前状态 DINO 评估。该检查未使用 ImageNet 原图，不代表完成长时间训练或默认大 batch 的显存与收敛验证。
