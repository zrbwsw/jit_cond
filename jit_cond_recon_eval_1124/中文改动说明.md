# jit_cond_recon_eval_1124：两阶段重建评估工具

基于 `jit_cond_dino_two_stage_1122_ddim_recon_noflip_pred_drop`，不含训练逻辑，
只做两件事：

1. **DinoDiT 特征重建**：加载已有 Stage 1 ckpt，对 ImageNet train/val 做 invert→decode 往返，统计特征域 MSE / relative-L2 / patch-cosine，可直接替代 noflip 版内置的 `eval_recon`，用于评估任何 DinoDiT checkpoint（包括无重建 loss 的旧版 1122 ckpt）。

2. **Pixel JiT 像素重建**：加载已有 Stage 2 ckpt，以 DinoDiT 重建特征为 grounding，对同一批图像做像素流 invert→decode，统计像素 MSE / PSNR，并保存原图与重建图的并排对比 PNG，供目视检查两阶段管道的还原质量。

重建指标仅作监控，不参与任何训练目标。

## 两处新增代码

| 文件 | 内容 |
|---|---|
| `denoiser.py` | 新增 `invert_pixel` / `decode_pixel` / `reconstruct_pixel` 三个方法，与 Stage 1 的 `invert_dino_latent` / `decode_dino_latent` 对称 |
| `eval_pixel_recon.py` | 独立评估入口，支持分布式多卡，输出 `metrics.json` 和 `comparison.png` |
| `sh/eval_pixel_recon.sh` | torchrun 启动脚本，通过环境变量传入 checkpoint 路径 |

## 快速使用

```bash
cd /data0/zhangruobei/Work/jit_cond_ablation/jit_cond_recon_eval_1124

export IMAGENET_ROOT=/path/to/imagenet
export STAT=/path/to/dinov3b_rae_imagenet1k_stats.pt

# 评估已有的 1122 DinoDiT E160 + Pixel pred E160 checkpoint
DINO_CHECKPOINT=../jit_cond_dino_two_stage_1122/checkpoints/stage1-dinov3b-dinodit-b-e160/checkpoint-160.pth \
PIXEL_CHECKPOINT=../jit_cond_dino_two_stage_1122/checkpoints/stage1-dinov3b-dinodit-b-e160-stage2-pixeljit-b-dinodit-pred-e200/checkpoint-160.pth \
OUTPUT_DIR=eval_out/e160_pred \
NUM_IMAGES=2000 SAVE_IMAGES=64 \
bash sh/eval_pixel_recon.sh
```

运行结束后 `eval_out/e160_pred/` 下有：
- `metrics.json`：dino_mse / dino_relative_l2 / dino_patch_cosine / pixel_mse / pixel_psnr_db
- `comparison.png`：64 对原图（左）与重建图（右）并排

## 关键参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--steps_dino` | 25 | DinoDiT invert/decode 步数，与 Stage 1 训练保持一致 |
| `--steps_pixel` | 50 | Pixel JiT invert/decode 步数 |
| `--cfg_pixel` | 1.0 | 重建时建议保持 1.0（无 CFG），评估纯模型还原能力 |
| `--cfg_dino` | 1.0 | 同上 |
| `--num_images` | 2000 | 评估图数，val 集上快速检查用 2000，完整评估用 50000 |
| `--save_images` | 64 | 保存对比图的数量，0 表示不保存 |
| `--split` | val | train 或 val |

## 与 noflip recon 版内置评估的区别

| | `eval_recon.py`（noflip 内置） | `eval_pixel_recon.py`（本工具） |
|---|---|---|
| 评估目标 | 仅 DINO 特征域 | DINO 特征域 + 像素域 |
| 是否需要重建 loss 训练 | 是（EMA teacher） | 否，可评估任意 ckpt |
| 像素对比图 | 无 | 有 |
| 适用 checkpoint | noflip recon 系列 | 任意 DinoDiT + Pixel JiT 组合 |
