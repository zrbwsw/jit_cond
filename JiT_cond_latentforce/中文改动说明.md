# JiT-B + DINOv3 patch-level AdaLN 消融说明

本文说明 `JiT_cond/` 相对于原始 `JiT/` 的改动，以及为什么这些改动可以验证“干净图像的语义 patch token 通过 patch-level AdaLN 注入，是否有助于生成”的假设。代码中的行号以当前版本为准；代码继续变化后，以相邻函数名为准。

## 1. 原始 JiT 的 AdaLN 条件粒度

原始实现的条件是每个样本一个向量：

```text
t_emb = TimestepEmbedder(t)       # [B, D]
y_emb = LabelEmbedder(y)          # [B, D]
c = t_emb + y_emb                 # [B, D]
```

在原始 [`JiT/model_jit.py`](../JiT/model_jit.py) 的 `JiTBlock.forward` 中，`c` 经过一个线性层得到 6 组 AdaLN 参数：

```text
[shift_msa, scale_msa, gate_msa,
 shift_mlp, scale_mlp, gate_mlp] = Linear(D, 6D)(c)
```

这些张量的形状是 `[B,D]`。随后原始 `modulate` 将它们 `unsqueeze(1)` 成 `[B,1,D]`，再广播到该样本的所有图像 token `[B,N,D]`。因此，原始 JiT 中同一个样本的所有 patch 共用同一组 shift、scale 和 residual gate；这就是“全局 AdaLN 条件”。

原始 `FinalLayer` 也使用同样的全局 `c` 生成 `[B,D]` 的 shift/scale，并广播到全部输出 patch。JiT 的 in-context class token 是另一条路径：它是重复的 `y_emb` 加位置参数，不改变上述 AdaLN 的全局粒度。

## 2. 本消融的条件构成

本项目仍保留时间和类别条件，并额外加入干净图像的 DINOv3 patch token：

```text
c_global[b]       = t_emb[b] + y_emb[b]                    # [B,D]
g[b,n]             = W_g(dino_patch[b,n])                   # [B,N,D]
c_patch[b,n]      = c_global[b] + g[b,n]                    # [B,N,D]
```

其中：

- `dino_patch` 是冻结的 DINOv3-B/16 从 clean image 提取的 patch token，宽度为 768；
- `W_g` 是新增的 `grounding_proj`，把 DINO 的特征宽度投影到 JiT-B 的 `hidden_size=768`；
- `c_global` 仍然负责时间和类别信息，DINO 分支只提供随空间位置变化的附加语义条件；
- JiT-B/16 在 256×256 输入上有 16×16=256 个 image patch，DINOv3-B/16 也产生相同网格，因此默认无需插值。`_prepare_grounding` 对其他方形 token 网格提供双线性调整能力。

代码位置：

- [`model_jit.py` 的 `JiT.__init__`](model_jit.py)：`grounding_dim` 和 `grounding_proj`；
- [`model_jit.py` 的 `_prepare_grounding`](model_jit.py)：输入检查、投影和网格调整；
- [`model_jit.py` 的 `JiT.forward`](model_jit.py)：计算 `c_global`，再构造 `c_patch`。

## 3. 如何从 global AdaLN 改为 patch-level AdaLN

改动重点不是为每一个 patch 新建一套参数，而是让同一个 AdaLN 线性层沿 token 维逐位置计算：

1. [`model_jit.py` 的 `modulate`](model_jit.py) 同时接受 `[B,D]` 和 `[B,N,D]`。前者仍自动扩展为 `[B,1,D]`，后者不扩展，因此可以逐 patch 调制。
2. `JiTBlock.forward` 接收 `patch_condition`。没有 grounding 时走原始 `c_global`；有 grounding 时，对每个图像 patch 使用 `c_patch[b,n]`，再由同一个 `Linear(D,6D)` 生成该 patch 的 6 组参数。这样每个 patch 有自己的 shift/scale/gate。
3. JiT 在第 `in_context_start` 层插入 32 个 class token。它们没有对应的 DINO patch，所以代码把 `c_global` 复制给 prefix token，再与 `[B,N,D]` 的 image-patch 条件拼接；图像 token 仍使用 patch-level 条件。见 `JiTBlock.forward` 的 `num_prefix_tokens` 分支。
4. `FinalLayer.forward` 同样优先使用 `patch_condition`，使最后一次归一化和输出前调制也是逐 patch 的；没有 grounding 时保持原始路径。

因此，所谓 patch-level 是“条件值按 patch 不同”，不是“每个 patch 拥有独立的可训练 AdaLN 层”。所有 patch 共享 AdaLN 的权重，差异来自各位置的 DINO token。

## 4. 训练阶段的 clean-image token

[`denoiser.py` 的 `Denoiser.forward`](denoiser.py) 保持原 JiT 的 flow/noise 路径：输入 clean image `x`，采样 `t` 和噪声 `e`，得到 noisy state `z`，然后预测速度场。

在构造 `z` 之前，若没有传入缓存 token，代码用原始 clean image 调用 `encode_grounding(x)`。[`grounding.py` 的 `DINOv3GroundingEncoder`](grounding.py) 完成 `[-1,1] → [0,1]`、ImageNet 标准化和 DINOv3 的 patch-token 提取；DINO 权重 `requires_grad=False` 且 `no_grad`，不会被 flow loss 更新。训练的可学习部分是 JiT 和 `grounding_proj`。

所以训练时的条件是：模型看到的是 noisy `z`，但 grounding token 来自同一个样本的 clean target image。这是本消融要验证的 teacher/clean-semantic 条件设定。

## 5. 采样阶段的 token 来源

[`denoiser.py` 的 `Denoiser.generate`](denoiser.py) 支持三种使用方式：

- 传入 `grounding_tokens`：直接使用预先提取的 token；
- 传入 `clean_images`：函数内部提取一次 token，适合重建或 teacher-forced 实验；
- 普通 class-only 采样且开启默认 `auto_grounding`：每个 ODE step 先用不带 grounding 的 `t+y` 路径得到 clean estimate，再裁剪到 `[-1,1]`，提取 DINO token，最后执行带 patch-level AdaLN 的条件路径。这样没有真实 clean image 时仍会执行 grounding 分支，但每个采样步会增加一次 DINO 前向。

CFG 的 conditional 和 unconditional 分支使用同一组 grounding token，类别差异仍由 `y`（以及 null class）提供。若要测原始 `t+y` 采样，可使用 `--no-auto_grounding`。

## 6. 参数量增加

以默认 JiT-B/16 为例，`hidden_size=768`，DINOv3-B/16 的 token 宽度也是 768。新增投影层为：

```text
grounding_proj = Linear(768, 768)
参数量 = 768 × 768（权重） + 768（bias）
       = 590,592 个参数 ≈ 0.591M
```

按当前 JiT-B/16 配置逐项统计，原始 JiT 的可训练参数为
`131,123,712`（131.124M），加入 `grounding_proj` 后为
`131,714,304`（131.714M），增加比例约 0.45%。统计不包含固定的二维
正弦位置编码，也不包含 `requires_grad=False` 的 DINOv3 参数。

如果直接统计 JiT 网络的全部 `state_dict` 张量（包含固定位置编码），
对应数值是 `131,320,320` 增加到 `131,910,912`；两种统计口径的增量都
是 590,592。

原有 `JiTBlock.adaLN_modulation` 和 `FinalLayer.adaLN_modulation` 的权重形状没有改变，只是从 `[B,D]` 改为对 `[B,N,D]` 逐 token 调用同一层。因此 patch 数 `N=256` 不会把 AdaLN 参数乘以 256；也没有为每个空间位置建立独立参数表。

- **可训练参数增加**：仅 `grounding_proj` 的约 0.591M（约 2.36 MB，按 FP32 权重计；约 1.18 MB，按 BF16 计）；
- **AdaLN 参数增加**：0；
- **DINOv3 参数**：作为冻结 teacher 载入并参与前向显存占用，但不参与优化器、EMA 或训练参数统计。当前代码注释中给出的 DINOv3-B 状态约为 343 MB（FP32 量级），这属于运行时/权重存储开销，不是本消融新增的可训练参数；
- 保存 checkpoint 时，`model` 主字典会保存一份冻结的 DINOv3 状态以便恢复；`util/misc.py` 的 `model_ema1/2` 只保存可训练参数，不会再重复保存 DINO。
- **计算量增加**：训练阶段增加一次冻结 DINOv3 前向；默认自动 grounding 采样阶段每个 ODE step 增加一次 DINOv3 前向。AdaLN 线性层对 256 个 token 的逐点计算会增加激活计算，但不增加参数量。

这个参数设计使实验对比更干净：性能变化主要来自“是否使用 clean semantic patch token 以及其 patch-level 注入方式”，而不是为每个 patch 引入大量独立模型参数。

## 7. 与 baseline 对齐时的注意事项

- 将 `--use_grounding` 关闭时，`grounding_dim=None`，模型回到原始 `t+y` AdaLN 路径，`modulate` 的全局广播行为也保持不变。
- DINOv3、JiT、ImageNet 和 FID 的默认本地路径由 `resource_paths.py` 和 `sh/` 脚本配置；训练脚本默认 JiT-B/16、8 卡、全局 batch 1024、80 epoch。
- 由于 patch-level 模型新增了 `grounding_proj`，不能直接加载不含该层的原生 JiT checkpoint 作为完全匹配的权重；从头训练或从兼容的 JiT-cond checkpoint 继续训练。
